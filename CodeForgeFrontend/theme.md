# CodeForge Theme

## Direction

CodeForge uses a premium cloud-IDE visual language: dark, technical, focused, and quietly futuristic. The interface should feel like a professional developer tool rather than a gaming or marketing site.

## Color

- Base background: near-black blue charcoal (`#080A0D`)
- Surfaces: translucent graphite panels with soft borders
- Primary text: cool off-white
- Secondary text: muted blue-gray
- React and interface accent: light blue (`#63B5FF`)
- Node.js accent: green (`#69A260`)
- Ambient contrast: restrained orange smoke used sparingly against the blue
- Framework colors belong to their cards and controls, not the whole page

## Typography

- Main typeface: Manrope for clear, modern product UI
- Technical labels and metadata: DM Mono
- Headings are compact, bold, and slightly tightened
- Supporting copy stays small, readable, and muted

## Surfaces and Layout

- Use thin borders, low-opacity backgrounds, and soft shadows
- Keep glass effects subtle and functional
- Prefer compact cards, clear spacing, and strong visual hierarchy
- The active framework card is the dominant element; neighboring cards add depth through scale, blur, and opacity
- Authentication panels use the same card language as the framework selector

## Motion

- Intro copy enters with opacity, blur, scale, and vertical movement
- Intro background uses two slow, blurred smoke fields: blue and orange
- Carousel movement uses smooth spring-like easing
- Hover states lift controls slightly and brighten borders
- Motion should support orientation and hierarchy, never distract from building

## Interaction Principles

- Framework selection works with arrow buttons, keyboard arrows, pointer dragging, and template tiles
- Authentication forms use clear labels, required fields, and visible feedback
- Primary actions use short verbs such as `Create workspace`, `Sign in`, and `Send reset link`
- The experience remains responsive, with partial neighboring cards retained on mobile
